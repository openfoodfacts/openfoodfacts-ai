# OCR Cleaning

Tools and utilities for cleaning and post-processing OCR (Optical Character Recognition) output.

## Features

- Multi-process OCR text cleaning
- Text post-processing and normalization
- Error correction for OCR artifacts
- Batch processing capabilities

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

### Multi-Process OCR Cleaning
```bash
python multiproc_ocr_cleaning.py
```

## Files

- `multiproc_ocr_cleaning.py` - Main script for parallel OCR text cleaning and post-processing
